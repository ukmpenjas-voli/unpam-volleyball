# UNPAM VOLLEYBALL

Website landing page premium untuk UKM/komunitas bola voli Universitas Pamulang.

## Struktur
- `index.html` — seluruh konten website
- `style.css` — desain, responsive layout, animasi
- `script.js` — menu mobile
- `assets/` — tempat foto/logo tim

## Cara upload ke GitHub Pages
1. Buat repository baru di GitHub, misalnya `unpam-volleyball`.
2. Upload semua isi folder ini ke repository.
3. Masuk **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/root`.
6. Save, lalu GitHub akan memberikan alamat website.

## Yang perlu diganti
- Link Google Form pada bagian `#register` di `index.html`.
- Nama/jabatan pengurus sesuai data resmi terbaru.
- Jadwal latihan.
- Lokasi/iframe Google Maps.
- Kartu galeri dengan foto asli tim.
- Logo resmi jika sudah tersedia.

Website ini menggunakan Google Fonts melalui CDN. Jika ingin sepenuhnya offline, font dapat diganti dengan font lokal.
