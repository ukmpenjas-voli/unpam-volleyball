# ASSETS UNPAM VOLLEYBALL

Masukkan file sesuai folder:

- logo/      → logo resmi UNPAM Volleyball
- pemain/    → foto pemain/atlet
- pengurus/  → foto pengurus/struktur organisasi
- galeri/    → foto latihan, pertandingan, event
- agenda/    → poster agenda/kegiatan
- icons/     → ikon/favicon tambahan

Nama file sebaiknya sederhana, misalnya:
logo-unpam.png
ketua-rudi.jpg
dede.jpg
latihan-01.jpg
pomprov-01.jpg

File `.gitkeep` hanya berfungsi agar folder kosong tetap terlihat saat di-upload ke GitHub.
